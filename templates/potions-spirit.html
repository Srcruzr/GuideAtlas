This is the area where you can combine potions to get better event summons:

Here we can see all the combinations we need and what we will get if we combine the necessary potions.

All the potions are from the event, but the potions you need to combine the event potions are all from the first island departure.
If you want to know more about the potions on Departure Island, we have a complete guide to it: All Wizard Alchemy Potions and Effects (Departure Isle)

If you manage to obtain and combine the potions correctly, you can summon all these beasts.
